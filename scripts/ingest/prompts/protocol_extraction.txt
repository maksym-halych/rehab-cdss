<extraction_rules>
    1. EXERCISES vs CLINICAL INTERVENTIONS: 
    - If the text mentions passive modalities or manual therapy (e.g., "Ice", "Massage", "Joint mobilizations", "TENS", "Ultrasound"), put them in `clinical_interventions`.
    - ONLY put active/passive movements performed by the patient themselves into `patient_exercises`.
    
    2. SPLIT MULTIPLE EXERCISES:
    - If the text lists multiple exercises in a single sentence, YOU MUST SPLIT THEM into separate ExerciseItem objects.
    - BAD: raw_name: "Leg press, bicycle and knee extensions"
    - GOOD: 
        {raw_name: "Leg press"}, 
        {raw_name: "Bicycle"}, 
        {raw_name: "Knee extensions"}
    
    3. SEPARATE SPECIFICATIONS:
    - Keep `raw_name` as clean as possible (just the exercise name). Move dosages, constraints, and specific techniques into `specifications`.
    - Clinical purpose/rationale (e.g., "to correct valgus", "for glute activation") goes in `clinical_rationale`, NOT in raw_name.

    4. NON-PHASED GUIDELINES: If the document is classified as Guideline_General and lacks
    specific chronological phases (e.g., weeks/months), place all interventions into a
    single section titled "General Recommendations" and leave progression_criteria as an
    empty array to avoid hallucinated timelines.

    5. NESTED PROTOCOLS: If the document contains nested sub-programs (e.g., a
    'Return to Running Program' at the end of an Achilles protocol), extract them
    as separate sections but prefix their titles with the sub-program name
    (e.g., 'Return to Running - Phase 1').

    6. MATRIX/CONDITIONAL DATA: If the text contains tables or rules that depend on
    specific conditions (e.g., different ROM limits depending on 'Patella graft' vs.
    'Femoral Condyle graft'), extract them as conditional statements into the
    precautions or goals array. Format example: 'If Patella graft: 0-40 deg ROM only'.

    7. MULTI-REGIONAL PROTOCOLS: If a document covers multiple joints (e.g., shoulder
    AND elbow, or hip AND knee), list ALL applicable regions in `primary_body_parts`.
    Do not restrict to one region.

    8. TARGET CONDITIONS: Include BOTH medical diagnoses AND biomechanical/functional
    deficits. Do NOT leave empty for corrective protocols (e.g., add 'Dynamic Knee
    Valgus', 'H:Q Ratio Deficit', 'Strength Asymmetry' where the protocol addresses them).

    9. CORRECTIVE/BIOMECHANICAL PROTOCOLS: For Guideline_General documents that address
    multiple faults or deficits, map EACH fault/deficit to a SEPARATE ClinicalSection.
    Use the section title to state the problem (e.g., 'Dynamic Knee Valgus', 'Heel Rise
    Deficits'). Do NOT lump all interventions into a single "General Recommendations" section.

    10. LATERALITY NEUTRALITY: Never hardcode "Left" or "Right" in extracted
    guidelines, precautions, or dosage unless anatomically absolute (e.g., heart).
    Convert to relative clinical terms: "Involved limb" / "Uninvolved limb",
    "Affected side" / "Unaffected side", or "Weaker side" / "Stronger side".
    For exercise raw_name, keep the movement name neutral (e.g., "Leg raise");
    if the source specifies a side, put "involved limb" or "affected side" in
    specifications (e.g., specifications: "involved limb, 3x10").
</extraction_rules>
